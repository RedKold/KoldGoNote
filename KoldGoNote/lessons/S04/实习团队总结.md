
## 关键成果和结论

在整个实习过程中，我们团队围绕 **券商知识库建设与智能体搭建** 展开了系统性的探索和实践，逐步形成了一套较为完整的应用方案。

### 1. 大模型与知识库建设

首先，在 **模型部署与选型** 阶段，我们通过 Docker + Ollama 成功部署了 **DeepSeek** 与 **Qwen** 等多种开源大模型。团队分成两组，分别对 **DeepSeek:32B** 与 **Qwen:32B** 模型进行性能对比测试，从推理速度、召回准确率、输出稳定性等多个维度进行评估，为后续的知识库应用奠定了坚实基础。

在模型选型之后，我们重点研究了 **Dify** 与 **RAGflow** 等工具的应用效果。团队成员分别完成了 Dify 与 RAGflow 的独立部署，并在此基础上开展了知识处理的系统优化：

- **知识分段**：探索了多种文本切分策略，提高长文本召回的覆盖度。
    
- **向量化嵌入**：利用不同 embedding 模型进行对比，提升相似度计算的精准度。
    
- **检索方式实验**：比较了向量检索、全文检索、混合检索的实际效果，并结合 **rerank 技术** 显著提升了召回结果的相关性。
    

同时，在 **Prompt 工程** 上，我们设计了多轮优化策略，有效降低了大模型在知识问答应用中的“幻觉”问题。

### 2. 智能体应用与工具集成

在智能体搭建阶段，我们重点研究了 **Dify 智能体与 Function Calling 技术结合** 的实践路径，使智能体具备了任务规划、参数提取和工具调用的能力。

在证券业务场景下，团队开发了多个实用工具型接口，例如：

- **客户资产负债查询接口**：通过数据库映射，支持自然语言输入直接查询客户资产与负债数据。
    
- **保证金维持担保比例计算接口**：可根据用户输入的目标维保比例或目标资产规模，自动计算所需转入的现金/证券市值，给出直观的维保结果。
    

例如，以下为 **保证金维保计算后端逻辑代码示例**：

```python
def calculate_maintenance_ratio(total_assets, total_liabilities):
    if total_liabilities == 0:
        return float('inf')
    return round(total_assets / total_liabilities * 100, 2)

def compute_required_asset_in(current_assets, current_liabilities, target_maintenance):
    required_assets = (target_maintenance / 100) * current_liabilities
    asset_in = max(0, required_assets - current_assets)
    return asset_in
```

### 3. 团队协作与开发流程

在工作模式上，我们采取了 **7人分工 + 定期交流 + 共同迭代** 的工作流：

- 每位成员负责一个子模块，例如大模型部署、知识库预处理、检索优化、接口开发、参数提取、前端展示、智能体集成等。
    
- 每周召开例会分享各自进展，遇到问题及时讨论与交叉协助。
    
- 在关键模块（如 Function Calling 调试、知识库检索优化）中，采用 **pair programming**（结对编程）的方式解决难题。
    

这种分工协作模式大大提升了团队效率，同时也促进了成员间的知识互补与能力成长。

### 4. 关键经验与成果总结

在反复的实践与迭代中，团队逐步解决了包括 **Function Calling Agent 黑盒调试**、**知识库召回率不足**、**接口鲁棒性不足** 等难题，并沉淀出如下经验：

- **RAG 技术的应用优势与局限**：在证券知识库场景下，RAG 可以快速落地，但仍需 rerank 和 prompt 工程优化才能达到较高的可用性。
    
- **大模型与后端系统的深度结合**：通过 API、数据库接口与智能体的集成，实现了“自然语言 → 精确数据 → 可视化结果”的完整链路。
    
- **可扩展的智能体架构**：形成了一套能够支持证券业务扩展的智能体设计方案，为未来更多场景（如投研问答、风控预警、合规审查）奠定了基础。
    

最终，团队在实习中实现了从 **模型选型 → 知识库建设 → 智能体集成 → 金融业务应用落地** 的完整闭环探索，证明了大模型与智能体在券商业务中具有可观的应用前景与实用价值。
