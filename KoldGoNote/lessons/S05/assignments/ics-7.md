### 3
假定一个虚拟存储系统的虚拟地址为 40 位，物理地址为 36 位，页大小为 16KB。若页表中有效位、访问权限位、修改位、使用位，共占 4 位，磁盘地址不记录在页表中，则该存储系统中每个进程的页表大小为多少？如果按计算出来的实际大小构建页表，则会出现什么问题？

虚拟地址为 40 位，每个虚拟页大小为 `16KB = 14 bit`，故有 `26bit` 宽的 (`2^26`) 个虚拟页

物理页面和虚拟页面大小相同，所以有 `2^22` 个物理页

页表项 PTE: `valid + access bit + dirty bit + use bit + physical bit = 4 + 22 = 26`，由于对齐，我们使用 `32bit = 4B`

我们有 `2^26个` PTE
所以实际大小为 `2^26 * 4B = 2^28 B = 2^8 MB = 256 MB`

**每个进程对应一个页表**，一个页表如果就 256MB，就会出现操作系统很容易爆内存问题。总结一下：
	 **如果按实际大小构建**，会出现页表过大，无法装入内存的问题。
