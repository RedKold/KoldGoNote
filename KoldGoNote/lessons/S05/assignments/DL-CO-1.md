## 14
设一个变量的值为 `4098`，要求分别用 `32` 位补码整数和 IEEE 754 单精度浮点格式表示该变量（结果用 16 进制表示），并说明哪段二进制位序列在两种表示中完全相同，为什么会相同？

- `32` 位补码整数
	- `4098=0001 0000 0000 0010_2` 二进制表示
	- `0000 0000 0000 0000 0001 0000 0000 0010`
	- 补码：`0x00001002` 

- 单精度浮点：
	- 首位 `0`，表示正数
	- `7` 位 `E`
	- `4098=2^12+2^1=1.0000 0000 001_(2)x2^12`
	- 偏置常数 `127`, 故 `E=12+127=139`，二进制 `1000 1011`
	- 首位可以省略
- `0|100 0101 1000 0000 0000 1000 0000 0000`

二者的二进制序列：
`0000 0000 0000 0000 0001 0000 0000 0010`
`0100 0101 1000 0000 0000 1000 0000 0000`
- 比对可以发现, 二者有公共子串 `0000 0000 0010`
这是因为，`4098` 是一个正数，所以 `4098` 的补码表示和 `4098` 的二进制表示是一样的，而 `4098` 在表达尾数时候，利用了科学计数法，其本质也是用二进制表示 `4098`，并进行移位（科学计数法）
- 故二者除了浮点数缺省了尾数头部的 `1` 以外，对 `4098` 的表示是相同的。区别只在这个串出现的位置。
## 17
假定在一个程序中定义了变量 `x`, `y`, `i` 其中，`x`, `y` 是 `float` 型变量，`i` 是 `16` 位 `short` 型变量（用补码表示）。程序执行到某一时刻，`x=-0.125`, `y=7.5`, `i=100`，它们都被写到了主存（按字节编址），其地址分别是 `100`, `108` 和 `112`。请分别画出在大端机器和小端机器上变量 `x`, `y` 和 `i` 中每个字节在主存中的存放位置。

#### Solution
每个字节是 8bit，

-  `x`: 
	- 符号 `1`
	- `0.125=2^(-3)=0.001_2=1*2^(-3)`

	- float 表示：
	- `1|011 1110 0|000 0000 0000 0000 0000 0000`
	- `HEX: BE00 0000`
	- big endian:

| ------- | ----- |
| 100     | BE    |
| 101     | 00    |
| 102     | 00    |
| 103     | 00    |
- small endian

| address | bytes |
| ------- | ----- |
| 100     | 00    |
| 101     | 00    |
| 102     | 00    |
| 103     | BE    |


- ` y`:
	- `0` 作为符号位
	- `7.5=(1.875)*2^(2)=(1+0.5+0.25+0.125)*2^(2)`
	- `E=2`, `bias=127`, `移码=129`, `1000 0001`
	- 尾数 `M=111 0000 0000 0000 0000 0000`
	- float: 
	- `0|100 0000 1|111 0000 0000 0000 0000 0000`
	- `HEX: 40F0 0000`
	- big endian
