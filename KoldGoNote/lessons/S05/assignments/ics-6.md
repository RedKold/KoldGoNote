### 3 
> [!Question] 主存
> 某计算机主存最大寻址空间为 4GB，按字节编址，假定用 $64M\times 8位$ 的具有 8 个位平面的 DRAM 芯片组成容量为 `512MB`，传输宽度为 64 位的内存条。回答
> 1. 每个内存条需要多少个 DRAM 芯片？
> 2. 构建容量为 2GB 的主存时，需要几个内存条？
> 3. 主存地址总共有多少位？其中哪几位用作 DRAM 芯片内地址？哪几位为 DRAM 芯片内的行地址？哪几位为 DRAM 芯片内的列地址？哪几位用于选择芯片？

1. `64M * 8bit = 64 MB`, so we need `512 / 64 = 8` 个 DRAM 芯片
2. 每个内存条是 `512MB=0.5GB`, 我们需要 4 个内存条
3. `4GB = 4 * (2^10)^3 = 2^32`，主存地址一共 `32` 位
	1. 芯片的组成为 `64 * (2^10)^2 = 2^26`, 故 13 位行地址，13 位列地址
	2. 一共有 `8` 个芯片，则需要 `3` 位选择芯片
### 4 
> [!Question] 某计算机按字节编址，已配有 `0000H ~ 7FFFH` 的 ROM 区域，现在用 `16K * 4 bit` 的 RAM 芯片形成 `32K * 8 bit` 的存储区域，CPU 地址线为 `A15 ~ A0`，回答如下问题

#### 1 RAM 区地址范围是什么？共需要多少个 RAM 芯片？地址线中哪一位用来区分 ROM 区和 RAM 区

我们需要在 RAM 之后分配，`32K * 8 bit = 2^5 * 2^10 * 8 = 2^18bit = 2^15 Byte = 0x8000 byte`, 由于按字节编址，计算 `7FFFH + ` 地址范围: ` 8000H ~ FFFFH `

我们需要的芯片： `32K * 8 / 16K * 4 = 4` 个

地址线的第一位用来区分 ROM 区和 RAM 区（可见他们只有第一位不同，RAM 第一位 1，ROM 第一位 0）

#### 2 假定 CPU 地址线改为 24 根，地址范围 `00 0000H ~ 00 7FFFH` 为 ROM 区，剩下的所有地址空间都用 `16K * 4位` 的 RAM 芯片配置，则需要多少个这样的 RAM芯片？

剩下的地址空间有 `32 K *8bit * 2^4^2`
需要 `2*2*2^8 ` =1024 个 RAM 芯片

### 5
> [!Question] 数据块操作
>  假设一个程序重复地将磁盘上一个 `4KB` 的数据块读出，进行相应处理后，再把数据写回到磁盘的另外一个数据区。各数据块内的信息在磁盘上连续存放，并随机地位于磁盘的一个信道上。磁盘转速为 `7200r/min`，平均寻道时间为 `10ms`，磁盘最大内部数据传输速率为 `40MB/s`，磁盘控制器的开销为 `2ms`，没有其他程序使用磁盘和处理器，并且磁盘读写操作和磁盘数据的处理时间不重叠。若程序对磁盘数据的处理需要 20000 个时钟周期，处理器时钟频率为 `500MHz`，则该程序完成一次数据块“读出-处理-写回”的操作所需的时间为多少？每秒钟可以完成多少次这样的数据块操作？

- 读出
	- 控制器开销 `2ms`
	- 寻道 `10ms`
	- 加载 `4KB / 40MB/s = 0.1ms`
	- 平均旋转等待时间:  `0.5 r / 7200r/min = 4.17ms`
- 处理
	- `20000 * 1/500 MHz = 0.4ms`
- 写回
	-  控制器开销 `2ms`
	- 寻道 `10ms`
	- 加载 `4KB / 40MB/s = 0.1ms`
	- 平均旋转等待时间:  `0.5 r / 7200r/min = 4.17ms`
时间总和：

`2 * (2 + 10 + 0.1 + 4.17) + 0.4 = 32.94 ms`

则完成的操作数为 `1/32.94ms = 30` 次

### 8 主存和 Cache。
假设某计算机主存地址空间大小为 `1GB`，按字节编址，cache 数据区大小为 `64KB`，块大小为 `128B`，采用直接映射和全写（write-through）方式。回答下列问题：

#### 1 主存地址如何划分？要求说明每个字段的含义、位数和在主存地址中的位置


主存地址 `1GB`：所以需要贮存地址 `30 bit`

cache 最多容纳主存块：`64KB / 128 B = 0.5 * 2^10 = 2^9` ，所以分 set 需要 `9` bit
`128B = 2^7`, 所以偏移量 `offset` 需要 `7` bit
至于 `tag`，需要 `30-9-7 = 14bit`

| 地址字段          | 含义                    | 位数   | 范围                 |
| ------------- | --------------------- | ---- | ------------------ |
| 标记位（Tag）      | 区分映射到同一 cache 块的不同主存块 | 14 位 | A₁₆ ~ A₂₉（最高 14 位） |
| 块索引位（Index）   | 定位主存块映射到 cache 的具体块位置 | 9 位  | A₇ ~ A₁₅（中间 9 位）   |
| 块内偏移位（Offset） | 定位某 cache 块内的具体字节     | 7 位  | A₀ ~ A₆（最低 7 位）    |

#### 2 cache 的总容量是多少位

cache `64KB = 2^16 B = 2^9 lines * 2^7 B(block)`
共 `2^9 = 512` 行
其中每行存储 `1 bit valid`, `14 bit tag`, 还可以存储 `128 B = 1 Kb ` 的数据
即
 `512 * ( 1 + 14 + 1024) = 531.97 K bit`

### 12 局部性探讨
以下是计算两个向量点积的程序段
```c
float dotproduct (float x[8], float y[8]){
	float sum = 0.0;
	int i,;
	for (i=0; i<8; i++){
		sum += x[i] * y[i];
	}
	return sum;
}
```

1. **时间局部性**和空间局部性分析
该程序在循环中每次迭代都访问 `x[i]` 和 `y[i]`，数组是连续的内存空间，所以空间局部性较好。
但是每次迭代都要重新访问，时间局部性较差。
cache 的命中率应当较高。但具体取决策略

2. 假设该段程序运行的计算机中的数据 cache 采用直接映射方式，数据区大小为 32B，主存块大小为 16B；变量 sum 和 i 分配在寄存器中，数组 x 存放在 `0000 0040H` 开始的主存区域，数组 y 紧跟在 x 后。试计算该程序中数据访问的命中率，要求说明每次访问时 cache 的命中情况
`float` 类型需要 `32` bit = `4B`。cache 可以存储 2 个块。

我们的数组一共 `64B`，装在 4 个块
假设 `0000 0040H` 开始的是 `A` 块，是第 `k` 块，`k%2==0` 存入 0 块，`k%2==1` 存入 1 块
`0000 0040H - 0000 004F A`
`0000 0050H - 0000 005F B`
...

映射关系：
cache 中一共就两个块，地址 A  偏移 mod2 存入 cache
```
elements	mm		cache		hit
x[0]		0040H	0			miss, store x[0]
y[0]		0060H	0			miss, store y[0]
x[1]		0044H	0			miss, store x[1]
y[1]		0064H	0			miss, store y[1]
x[2]		0048H	0			miss, store x[2]
y[2]		0068H	0			miss, store y[2]
x[3]		004cH	1			miss, store x[3]
y[3]		006cH	1			miss, store y[3]

以此类推
```
总之，由于 `x[i]` 和 `y[i]` 总是先后访问同一个 cache，导致从未正确 hit （技术实现上是靠 tag 标记主存位置的）

3. 改为 2 路组相联映射方式，块大小改为 8B，其他条件不变，则该程序访问的命中率是？

cache 可以存储 4 个块

映射方式 2 路组相联。每一组 2 行，则需要 2 组。

映射关系：

| i     | x         | 对应块号 | y         | 对应块号 |
| ----- | --------- | ---- | --------- | ---- |
| 0     | 0x0000040 | A    | 0x0000060 | F    |
| 1     | 0x0000044 | A    | 0x0000064 | F    |
| 2     | 0x0000048 | B    | 0x0000068 | G    |
| 3     | 0x000004c | B    | 0x000006c | G    |
| 4     | 0x0000050 | C    | 0x0000070 | H    |
| 5     | 0x0000054 | C    | 0x0000074 | H    |
| 6     | 0x0000058 | D    | 0x0000078 | I    |
| 7<br> | 0x000005c | D    | 0x000007c | I    |
- `i=0`, load A block into cache, then `x[0]` miss, but `x[1]` hit.
- one by one, similarily
- `50%`

4. 在上述（2）中条件不变的情况下，将数组 `x` 定义为 `float x[12]`，命中率又是多少？

改变的是 Y 的地址。现在从 `0x00000040 + 12 * 0x4 = 0x70` 

| i   | x         | 对应块号 | y         | 对应块号  |
| --- | --------- | ---- | --------- | ----- |
| 0   | 0x0000040 | A    | 0x0000070 | D     |
| 1   | 0x0000044 | A    | 0x0000074 | D     |
| 2   | 0x0000048 | A    | 0x0000078 | D     |
| 3   | 0x000004c | A    | 0x000007c | D     |
| 4   | 0x0000050 | B    | 0x0000080 | E     |
| 5   | 0x0000054 | B    | 0x0000084 | E     |
| 6   | 0x0000058 | B    | 0x0000088 | E     |
| 7   | 0x000005c | B    | 0x000008c | E<br> |

这样一凑的话，A C E 映射到 0cache， B D 映射到 1cache
则访问 `x[0]` 第一次 miss，之后对 A 的访问都 hit
`y[0]` 也是同理，第一次 miss，之后都可以

总体命中率 `75%`
