
## 常用公式
### 分位数估计公式
- 统计学/风险管理常用
$$
\hat{\nu}_{\beta}=\inf\{ x:\hat{F}_{X,n}(x)\geq 1-\beta \}
$$
- $\hat{\nu}_{\beta}$ 是分位数的估计值
- $\hat{F}_{X,n}(x)$ **是经验分布函数**
- $1-\beta$ 是一个给定的概率水平
- $\inf$ 表达取满足条件的最小 $x$
因此，这个公式的意思是：

> 找到最小的 $x$，使得样本经验分布在 $x$ 处的累积分布值不小于 $1-\beta$。

用更直白的话说，它就是经验分布的 $1-\beta$ 分位数估计

$$

## Rando-Nikodym 定理
### Def 测度的绝对连续，等价；$\sigma$ -有限测度

1) 设对同一个 $\sigma$ -代数上两个测度 $\mathbb{P}$, $\mathbb{Q}$，若 $\forall E\in \mathcal{F}$, $\mathbb{P}(E)=0\implies \mathbb{Q}(E)=0$ 则称 $\mathbb{Q}$ 对 $\mathbb{P}$ **绝对连续**，记作 $\mathbb{Q}\ll\mathbb{P}$
	- 实际是对绝对连续实函数的推广
2) $\mathbb{Q}\ll \mathbb{P}$ 且 $\mathbb{P}\ll\mathbb{Q}$，则 $\mathbb{P、Q}$ 等价
3) 设 $\Omega$ 的一个代数 $S$ 上建立测度 $\mu$，若 $S$ 中存在一子集列 $\{ E_{i} \}_{i=1}^{\infty},\;s.t.\;\cup_{i=1}^{\infty}E_{i}=\Omega$ 满足 $\forall i,\mu(E_{i})<\infty$, 则称 $\mu$ 为 $\sigma$ **-有限**。
	1) 显然概率测度为 $\sigma$ 有限 (sigma-finite)

### Thm Randon-Nikodym 定理
设 $\mathbb{P},\mathbb{Q}$ 为同一可测空间 $(\Omega,\mathcal{F})$ 上的两个 $\sigma$ -finite 测度. 当 $\mathbb{Q}\ll\mathbb{P}\Rightarrow$ 一定 $\exists$ 一个 $\mathcal{F}$ -可测函数 $\Lambda(\omega):\Omega\to\mathbb{R}$, 使得 $\forall E\in\mathcal{F}$ 且 $\mathbb{P}(E)\neq0$ 有 $\mathbb{Q}(E)\equiv\int_Ed\mathbb{Q}=\int_E\Lambda d\mathbb{P}.$ 则记 $\frac{d\mathbb{Q}}{d\mathbb{P}}(\omega):=\Lambda(\omega)$, 称为 $\mathbb{Q}$ 对 $\mathbb{P}$ 的**R-N 导数。**

- 容易看到这是两个测度转化的一个重要的“形变量”的度量。


#### 和重要性采样的关系
重要性采样的基本形式：
- 想求
$$
\mathbb{E}_{P}[f(X)]=\int f(x)dP(x)
$$
- $P$ 不好采样，比如不关注尾部等问题
- 引入另一个分布 $Q$,  如果 $P\ll Q$，就可以写成
$$
\mathbb{E}_{P}[f(X)]=\int f(x) {\frac{dP}{dQ}(x)dQ(x)}
$$
实际上，$\frac{dP}{dQ}$ 就是一个 **Randon-Nikodym**导数。
计算其的值就可以在新测度下估计。

### 考虑我们的 MES 模型，以及其 R-N 导数
$MES$ 的基本计算公式：
$$
\frac{\partial ES_{\alpha}}{\partial y_{i}}=-E[r_{i}|R\leq-VaR_{\alpha}] \equiv MES^i_{\alpha}
$$
要思考的是这样一个条件期望的 R-N 导数的计算

- **转化为**无条件测度
- 筛一遍采样。
- 例如

$$
E_{\mathbb{P}}[r_{i}|R\leq -VaR_{\alpha}]=\frac{{E_{\mathbb{P}}[r_{i}\cdot \mathbf{1}_{\left\{ R\leq -VaR_{\alpha}\right\} }]}}{\mathbb{P}(R\leq-VaR_{\alpha})}
$$
	- 这个只是“事件上的筛选”，没有独特的性质。
	- 记录 $R\leq-VaR_{\alpha}$ 为事件 $A$
**新测度**$\mathbb{Q}$ 的设计

$$
\mathbb{E}_\mathbb{P}[f(X)\mid A]=\frac{\mathbb{E}_\mathbb{Q}\left[f(X)\cdot\mathbf{1}_A(X)\cdot\frac{d\mathbb{P}}{d\mathbb{Q}}(X)\right]}{\mathbb{E}_\mathbb{Q}\left[\mathbf{1}_A(X)\cdot\frac{d\mathbb{P}}{d\mathbb{Q}}(X)\right]}
$$

- 用正态分布 $\mathbb{Q}=\mathcal{N}(\tilde{\mu},\Sigma)$ 来做的话：
- 设原始分布 $X=(R,r_{i})\sim\mathbb{P}=\mathcal{N}(\mu,\Sigma)$

$$
MES_\alpha^i\approx-\frac{\sum_{j=1}^Nr_i^{(j)}\cdot\mathbf{1}_{\{R^{(j)}\leq-VaR_\alpha\}}\cdot w^{(j)}}{\sum_{j=1}^N\mathbf{1}_{\{R^{(j)}\leq-VaR_\alpha\}}\cdot w^{(j)}}
$$

- 其中 Rando-Nikodym 导数为
$$
w^{(j)}=\frac{p(X^{(j)})}{q(X^{(j)})}=\frac{\mathcal{N}(X^{(j)};\mu,\Sigma)}{\mathcal{N}(X^{(j)};\tilde{\mu},\Sigma)}
$$



```python
import numpy as np
from scipy.stats import multivariate_normal

# 原始分布 P: N(mu, Sigma)
mu = np.array([0.0, 0.0])  # [R, r_i]
Sigma = np.array([[1.0, 0.8],
                  [0.8, 1.0]])

# 重要性分布 Q: 均值偏左
mu_tilde = np.array([-2.0, 0.0])  # 强调 tail
Sigma_tilde = Sigma

# VaR 阈值
VaR_alpha = 1.5

# 样本数
N = 100000
samples = np.random.multivariate_normal(mu_tilde, Sigma_tilde, size=N)

# 分别取出系统回报 R 和个体 r_i
R = samples[:, 0]
r_i = samples[:, 1]

# 计算 R-N 导数（P/Q）
p_pdf = multivariate_normal.pdf(samples, mean=mu, cov=Sigma)
q_pdf = multivariate_normal.pdf(samples, mean=mu_tilde, cov=Sigma_tilde)
w = p_pdf / q_pdf  # Radon-Nikodym 导数

# 取落入 tail 的样本
mask = R <= -VaR_alpha
MES_numer = np.sum(r_i[mask] * w[mask])
MES_denom = np.sum(w[mask])

MES_estimate = - MES_numer / MES_denom
print("估计的 MES_alpha^i =", MES_estimate)

```

```python
def importance_sampling_mes(asset_returns, market_returns, alpha=0.05,
                             n_samples=10000, proposal_mu=None, proposal_Sigma=None, verbose=False):
    """
    使用重要性采样估计 MES（Marginal Expected Shortfall）
    利用真实历史数据计算 mu 和 Sigma

    参数:
        asset_returns (pd.Series): 资产收益
        market_returns (pd.Series): 市场收益
        alpha (float): VaR显著性水平
        n_samples (int): 采样数量
        proposal_mu (np.ndarray): 提议分布均值
        proposal_Sigma (np.ndarray): 提议分布协方差
        verbose (bool): 是否打印详细信息

    返回:
        MES_hat (float): MES 估计值
    """
    data, mu, Sigma, VaR, _ = prepare.prepare_data_for_mes(asset_returns, market_returns, alpha=alpha)

    # 使用原分布作为默认提议分布
    if proposal_mu is None:
        proposal_mu = mu
    if proposal_Sigma is None:
        proposal_Sigma = Sigma

    # 构建多元正态分布
    p_dist = multivariate_normal(mean=mu, cov=Sigma)
    q_dist = multivariate_normal(mean=proposal_mu, cov=proposal_Sigma)

    # 生成样本
    samples = q_dist.rvs(size=n_samples)  # shape = (n_samples, 2)
    r_i, r_m = samples[:, 0], samples[:, 1]

    # 计算权重
    weights = p_dist.pdf(samples) / q_dist.pdf(samples)

    # 计算 MES
    indicator = (r_m <= -VaR).astype(float)
    MES_hat = - np.sum(weights * r_i * indicator) / np.sum(weights * indicator)

    if verbose:
        print(f"采样总数: {n_samples}")
        print(f"满足条件的样本数: {np.sum(indicator)}")
        print(f"MES估计: {MES_hat:.6f}")

    return MES_hat

```

### 2025-8-21

#### 关于为什么移动-2 `sigma` 效果更好

如果你把均值移得太深（比如 -4σ）：

- 确实大部分样本都落在极端尾部；
- 但是此时 $\frac{p(x)}{q(x)}$ 差距过大，可能导致放大方差。（超级样本，扭曲了）
- 结果反而方差上升。

所以在重要性采样里存在一个 **最佳偏移量**（balance）：
- 移得太少 → 有效样本太稀疏，收敛慢；
- 移得太多 → 权重方差过大，收敛慢；

- _Monte Carlo Methods in Financial Engineering (Paul Glasserman)_ 对采样也有一部分介绍。
![image.png|700](https://kold.oss-cn-shanghai.aliyuncs.com/20250820231358.png)

- **我们的偏移符合这个假设**。所以关注尾部样本的同时也会带来- `大值/不可忽视的概率` 的情况，从而导致样本扭曲造成方差大。
- 这个可能导致 `-2sigma` 效果最好。



#### 是否可以尝试其他采样函数？
计算 MES 或一般尾部条件期望时：
- 如果直接用 `indicator = (R <= -VaR)`，属于硬截断，权重为 0，降低了可用性。
- 权重可能在 IS 中出现极端波动（爆炸），导致方差巨大。一个常用改进是 **soft-indicator**，用平滑函数代替 0/1 截断，例如 logistic 函数或 sigmoid 函数。
	- 采用平滑函数作为截断后，调整不同参数，基本也是-2sigma 效果最好。
	- `kappa=-2, log-log 拟合斜率=-0.4899,gamma=80`
	- `kappa=-2, log-log 拟合斜率=-0.4602,gamma=100`
	- 平滑方式：

$$
\mathbf{1}_{\{r_m\leq-\mathrm{VaR}\}}\approx\frac{1}{1+\exp\left(\gamma(r_m+\mathrm{VaR})\right)}
$$

## 阅读新文献，探讨数据分析方式
### 关于 IS estimator $\tilde{c}_{\alpha,\beta}$ 的 Consistency
#### **基本变量**：
- 已经找到了合适的 IS distribution，记作 $\tilde{f}(x,y)$
- 模拟样本 $\{ (\tilde{X}_{i},\tilde{Y}_{i}),i=1,\dots,n \}$
- **似然比**(这里应该和 RN 导数等价)
	- $\{ \ell_{i},i=1,\dots,n \}=\ell(\tilde{X}_{i},\tilde{Y}_{i})$

- $G(x,y)$ 的定义：
	- $G(x,y):=Pr(X\geq x, Y\geq y)$
	- $\tilde{G}_{n}(y)=\frac{1}{n}\sum_{i=1}^{n}1\{ \tilde{X}_{i}\geq \tilde{v}_{\beta},\tilde{Y}_{i}\geq y \}\ell(\tilde{X_{i}},\tilde{Y}_{i})$
		- 很好理解：**取出符合条件的样本**（indicator `1`），然后乘以似然比，就获得了对 $G(x,y)$ 的 monte carlo模拟。
	- 构造这个形式其实是为了方便表示 CoVaR，从而方便研究。
	- $\tilde{G}_{n}(y)$ 实际是对 $Z_{n}=1\{ \tilde{X}_{i}\geq \tilde{v}_{\beta},\tilde{Y}_{i}\geq y \}\ell(\tilde{X}_{i},\tilde{Y}_{i})$ 求期望
- ![image.png|400](https://kold.oss-cn-shanghai.aliyuncs.com/20250830205449.png)


#### 假设

- Assumption 1
	- Let $\mathcal{X}\subset \mathbb{R}$ be a neighborhood of $x=v_{\beta}$ and $\mathcal{Y}\subset \mathbb{R}$ be a neighborhood of $c_{\alpha,\beta}$.
	- $f_{X}(x)$ and $f(x,y)$ are continuously differentiable and positive in $\mathcal{X}$ and $\mathcal{X}\times\mathcal{Y}$, respectively
	- 两个邻域内都是连续可微，且都是正的
- Assumption 3 
	- For any $y\in\mathcal{Y}$, $G(x,y)$ is a twice differentiable function of x in $\mathbb{R}$
- Assumption 4
	- 似然比 $\ell_{X}(x)<C$ on $x \in(v_{\beta}-\varepsilon,v_{\beta}+\varepsilon)$, for some $C>0$ and $\varepsilon>0$
	- for a sufficiently small $\delta>0$ and $p>4+\delta$ such that $E[1\left\{ \tilde{X}\leq v_{\beta}+\varepsilon \right\}(\ell_{X}(\tilde{X}))^{P}]<\infty$
		- 保证四阶矩有限
	- 另外，对于似然比 $\ell(x,y)$, 要求 $E[(\ell(\tilde{X},\tilde{Y}))^{3}]<\infty$


- Lemma 5（可以通过 Assumptions 1,3,4 说明）

$$
\tilde{G}_{n}(y)\xrightarrow{p}E\left[ 1\{ \tilde{X}\geq \tilde{v}_{\beta},\tilde{Y}\geq y \} \ell\right],n\to \infty 
$$
- 如果我们增加 $\ell(\tilde{X},\tilde{Y})<C$，则该期望也有界（吗），知道：以概率 1 收敛
	- 如何保证的**强大数定律？**
$$
\tilde{G}_{n}(y)\xrightarrow{w.p.1}E\left[ 1\{ \tilde{X}\geq \tilde{v}_{\beta} ,\tilde{Y}\geq y\}\ell \right] ,n\to \infty
$$
	- ![image.png|700](https://kold.oss-cn-shanghai.aliyuncs.com/20250830203712.png)
	- 再想想：
		- $E\left[ 1\{ \tilde{X}\geq \tilde{v}_{\beta} ,\tilde{Y}\geq y\} \right]=\mathbb{P}_{Q}\{ \tilde{X}\geq \tilde{v}_{\beta},\tilde{Y} \geq y\}$ 在 Q 测度下？
		- 如果 $\ell_{i}$ 有界即 $\ell(\tilde{X}_{i},\tilde{Y}_{i})$ 有界，则该期望可以转化为原 $P$ 测度下的 $\tilde{X}\geq \tilde{v}_{\beta },\tilde{Y}\geq y$ 的概率，显然有界，故可以利用**强**大数定律。
