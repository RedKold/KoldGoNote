### 父子分段
首先，在知识库检索中会有**两种不利于生成准确回答**的情况：
- **检索的结果是比较准确的**，但是结果是从不同的分段中拿到的，**比较分散**，导致没有一个完整的上下文提供给 AI；
- **检索的结果不太精准**，比较泛化，和上面一条刚好相反，**上下文可能够了**，但是精准度不够。

**父子分段**简单来说是先整体后细化。
- **子模块匹配查询**：拆字块精确
- **父模块提供上下文**：然后根据匹配到的子块找到对应的父级，补充一下这块的信息，丰富一下匹配内容。

#### 关于 URI
## ✅ SQLAlchemy 数据库连接 URL 的通用格式：


`dialect+driver://username:password@host:port/database`

每一部分都有特定含义：

| 部分                  | 说明                   | 示例                                                   |
| ------------------- | -------------------- | ---------------------------------------------------- |
| `dialect`           | 数据库类型                | `mysql`, `postgresql`, `sqlite`, `oracle`, `mssql` 等 |
| `+driver`           | 可选，Python 用于连接数据库的驱动 | `+pymysql`, `+psycopg2`, `+pyodbc` 等                 |
| `username:password` | 登录数据库的用户名和密码         | `root:123456`                                        |
| `host`              | 数据库主机地址              | `localhost`, `host.docker.internal`, `127.0.0.1` 等   |
| `port`              | 数据库端口                | 如 MySQL 默认是 `3306`                                   |
| `/database`         | 要连接的数据库名称            | `mydb`                                               |

### 券商接口文档
#### 接口描述
该接口用于查询指定股票在指定日期的可充抵保证金证券折算率。请求会调用外部接口获取实时数据并返回。

---

#### 请求信息

- **请求URL**：`/haircut-rate`
    
- **请求方法**：POST
    
- **请求头**：
    - Content-Type: application/json
        
    - （可选）Authorization: Bearer \<token\> （如启用鉴权）

#### 请求参数

|参数名|类型|必填|说明|示例|
|---|---|---|---|---|
|code|string|是|股票代码|"000001"|
|day|string|是|查询日期，格式YYYY-MM-DD|"2025-08-11"|

请求体示例（JSON）：

```json
{
  "code": "000001",
  "day": "2025-08-11"
}
```

---

#### 响应参数

|参数名|类型|说明|
|---|---|---|
|code|int|状态码，0表示成功，非0表示失败|
|message|string|响应描述信息|
|status_code|int|外部接口返回的HTTP状态码|
|data|object/json|外部接口返回的详细数据|

---

#### 响应示例

成功响应：

```json
{
  "code": 0,
  "message": "Success",
  "status_code": 200,
  "data": {
    // 外部接口返回的JSON内容
  }
}
```

参数缺失：

```json
{
  "code": 1,
  "message": "缺少参数：code 或 day",
  "data": null
}
```

外部接口返回非JSON数据或解析失败：

```json
{
  "code": 3,
  "message": "外部接口返回数据解析失败",
  "data": null
}
```

内部服务器错误：

```
{
  "code": 500,
  "message": "内部错误: 错误描述",
  "data": null
}
```

---

#### 注意事项

- 该接口目前不强制登录鉴权（可根据需要启用`@jwt_required()`）。
    
- `code` 和 `day` 参数必须提供且格式正确。
	- 如果 day 不提供，会默认用今天的日期。
    
- 返回的`data`字段内容为调用外部接口的原始JSON数据，格式请参考对应外部接口文档。
    
- 若外部接口响应异常，该接口仍尝试返回响应内容，状态码包含在`status_code`字段。
